# Psychotherapy Placement Profile

Clinical placement CV and cover letter for **Mărioara Rus**, a first-year
MProf Psychotherapy trainee at Regent's University London.

## Published site

[marioararus.github.io/psychotherapy-placement-profile](https://marioararus.github.io/psychotherapy-placement-profile/)

The site includes:

- a placement-focused CV;
- a customisable cover letter;
- responsive layouts for mobile and desktop; and
- print styles for saving either document as a PDF.

## Edit locally

The site uses plain HTML and CSS and has no build step. Open `index.html`
directly, or serve the repository with:

```sh
python3 -m http.server 8000
```

GitHub Pages publishes the `main` branch from the repository root.
